Privacy Policy

Effective date: 23 November 2026

This policy covers the ALL_MOST_LOCAL website and ALL_MOST_LOCAL Publisher, an internal tool operated by Artūras Gromovas, owner of the ALL_MOST_LOCAL project ("we").

Who uses the tool

ALL_MOST_LOCAL Publisher is used only by the owner of the ALL_MOST_LOCAL channels, to upload and schedule the project's own videos on its own YouTube channel. It is not offered to the public, and it does not access the accounts or data of any other person.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

  • Through Google OAuth, with the owner's consent: permission to upload videos to, and manage videos on, the owner's own ALL_MOST_LOCAL YouTube channel.
  • The video files, titles, descriptions, tags and publishing times that the owner has approved for publication.
  • Basic information about the uploaded videos returned by the API (for example video ID, status and scheduled time), used to confirm that a publication succeeded.

How the data is stored and used

  • OAuth access credentials are stored only in the publisher's private configuration and on the owner's own computer. They are never published or shared.
  • Data is used only to upload, schedule and verify the project's own videos.
  • We do not sell, rent or share any data with third parties, and we do not use it for advertising.
  • We do not collect data from viewers of the channel through the tool.

This website

This website sets no cookies and uses no analytics. It is hosted on GitHub Pages; GitHub may log technical data such as IP addresses, as described in the GitHub Privacy Statement.

Revoking access and deleting data

Access granted to ALL_MOST_LOCAL Publisher can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. When access is revoked, the stored credentials stop working and are deleted from the tool's configuration within 30 days. To request deletion of any data related to the tool, write to the contact address below; we will delete it within 30 days.
